// about this project

How Sukoon works

Every message passes through a safety layer before anything else. If it signals risk, the AI is skipped entirely and a person-first safety response is shown with real helplines.

  1. 01Messagetyped in the browser
  2. 02Crisis triageseverity-weighted pattern rules, runs on-device first
  3. 03aSafety responsehelplines, no AI
    03bGrounded answerMiniLM retrieval → Llama 4 via Groq (live) · curated responses (demo)
  4. 04Privacy-first logmetadata only, session IDs hashed

Design principles

  • Low barrier. No account, no form. A mood check-in replaces a blank page.
  • Validate, then help. Replies reflect feelings before offering advice, as in person-centred counselling.
  • Body before words. Paced breathing and grounding work even when talking feels hard.
  • Honest about limits. It’s a companion, not a clinician, and it always points to humans.
